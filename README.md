# Unyt Accounting -- Maker of the Engines that drive Value Flows

In today's gig economy, there are many networks of loosely connected parties who activate value flows together. Think of Uber drivers and passengers, or AirBnB guests and hosts... A coordination tool lets them find each, and activates the value flows. 

Unyt builds these underlying value flow engines which can power [rideshare networks](https://github.com/unytco/unyt-sandbox-tx5/releases/tag/v0.42.0), [decentralized infrastructure](https://github.com/unytco/unyt-infra-marketplace), [local currencies](https://github.com/unytco/circulo-tx5) for economic devolpment, and much more. The system provides the same kinds of cryptographic data integrity guarantees as blockchains, but is lighter, faster, and completely P2P (no middlemen miners or stakers). 

Try out [one of our many releases](https://unyt.co/blog) to explore how we activate and track value flows.
